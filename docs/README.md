#  Zoo-Care

Лабораторна робота з дисципліни **"Веб програмування"**  
Тема: Об’єктно-орієнтоване моделювання та архітектура системи "Zoo-Care"



##  Опис проєкту
Zoo-Care — це навчальний проєкт, який моделює роботу системи догляду за тваринами у зоопарку.  
Основна мета — продемонструвати застосування принципів **ООП**, архітектурних рішень та документування у вигляді **ADR (Architectural Decision Records)**.



##  Ролі та сутності
- **Тварина**: вид, вік, стан здоров’я, дієта  
- **Працівник зоопарку**: ПІБ, спеціалізація, стаж  
- **Організація (Zoo-Care)**: назва, адреса, тип  



##  Функціональні можливості
- Реєстрація нових тварин  
- Призначення відповідального працівника  
- Ведення історії догляду та лікування  
- Збереження даних у структурованому форматі  



##  Архітектура
- **Мова програмування:** C++  
- **Файли проєкту:**
  - `main.cpp` — точка входу  
  - `oop_care.cpp` — реалізація класів та логіки  
  - `business_doc.md` — опис бізнес-логіки  
  - `docs/adr/` — архітектурні рішення
