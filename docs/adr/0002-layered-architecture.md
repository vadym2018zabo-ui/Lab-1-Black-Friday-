# ADR 0002: Шарова архітектура для моноліту

## Рішення
- `api/` — контролери, маршрути.
- `service/` — бізнес-логіка, валідація.
- `domain/` — сутності та інваріанти.

## Правила
- Виклики тільки зверху вниз: api → service → domain.
- Заборонено прямий доступ api → domain чи api → БД.
- Єдиний формат помилок: `{ "error": "...", "message": "..." }`.
