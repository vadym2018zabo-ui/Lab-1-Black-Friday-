# ADR 0001: Вибір архітектурного стилю

## Контекст
Ми розглянули два варіанти: модульний моноліт та мікросервіси.

## Рішення
Реалізувати CRUD у двох стилях:
- Модульний моноліт (шари api → service → domain).
- Мікросервіс (окремий сервіс для ресурсу items).

## Аргументи
- Мікросервіси: масштабованість, незалежний деплой.
- Моноліт: простота, менше інфраструктури.

## Статус
Прийнято.
